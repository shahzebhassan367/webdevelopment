Lightweight Phishing URL Detection Using Lexical Features and Ensemble Classifiers

Shahzaib Khan

Department of Computer Science

Air University

Islamabad, Pakistan

shahzaib.khan@example.com

Abstract—Phishing websites imitate trusted brands to steal credentials, and new phishing URLs appear faster than blacklists can be updated. This paper studies whether a small set of lexical features, taken only from the URL string, is enough to detect phishing links without downloading the page. We extract 18 features such as URL length, number of dots, presence of an IP address and suspicious keywords, and compare logistic regression, a decision tree and a random forest. On a balanced dataset of 20,000 URLs, the random forest reaches 96.1% accuracy and an F1-score of 0.96 while classifying each URL in under a millisecond, which makes it suitable for browser extensions.

Index Terms—phishing detection, URL analysis, machine learning, random forest, cyber security

Introduction

Phishing remains one of the most common entry points for cyber attacks. An attacker registers a look-alike domain, copies the login page of a bank or email provider and sends the link to victims. Blacklist-based defences only work after a URL has been reported, leaving a window in which new sites are dangerous.

Machine learning offers a proactive alternative: a model learns what phishing URLs look like and flags unseen ones. Content-based methods download and inspect the page, which is slow and can expose the user to malicious scripts. We therefore focus on lexical features that can be computed from the URL string alone.

Related Work

Ma et al. [1] showed that lexical and host-based URL features can separate malicious from benign sites with high accuracy. Sahingoz et al. [2] compared seven classifiers on natural-language features of URLs and found random forests performed best. Our study follows this line but limits itself to cheap features that run inside the browser.

Methodology

Dataset

We combined 10,000 phishing URLs reported to PhishTank with 10,000 legitimate URLs from popular websites, giving a balanced set. The data was split 80/20 into training and test sets with stratification.

Feature Extraction

Each URL is turned into an 18-dimensional vector. The most informative features are listed below:

  1. total URL length and hostname length;
  2. number of dots, hyphens and “@” symbols;
  3. use of a raw IP address instead of a domain;
  4. presence of words such as login, verify or secure;
  5. whether HTTPS is used;
  6. Shannon entropy of the hostname.

Entropy Feature

Randomly generated domains tend to have high character entropy, defined as

H = −Σc p(c) log2 p(c)(1)

where p(c) is the relative frequency of character c in the hostname.

Classifiers

We trained logistic regression (LR), a decision tree (DT) and a random forest (RF) with 100 trees [3], using the scikit-learn library [4] with default settings except for the number of trees.

Conclusion

Lexical URL features alone detect phishing links with over 96% accuracy using a random forest, without fetching page content. Future work will add domain-age information and test the model as a real-time browser extension.
